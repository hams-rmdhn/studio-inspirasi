# Studio Inspirasi 0.1.11

Desktop release of the Studio Inspirasi fork for macOS Monterey 12 (Intel) and the platforms Clovercut already ships.

## Launch screen

- Rename a recent project from its pencil button, in the grid or the list. A small sheet takes the new name; Return renames and Escape backs out. The name in the project and in Recent projects changes; the folder on disk keeps its own.
- Removing a project now asks first. On macOS the project folder is moved to the Trash and taken off the list — Studio Inspirasi cannot bring it back, the Trash can until it is emptied. A project whose folder has gone is simply taken off the list. Elsewhere Remove only takes a project off the list, as before.
- The list view's buttons are marks only — rename, show in folder, delete — in squares that never move.

## Fixes

- List view: the remove button no longer jumps between two places, or flickers, as the pointer nears it.
- Grid view: the poster buttons turn the accent colour on hover, so they read over a bright poster.
- Full screen: the title bar's mark moves in line with the page and the panels instead of keeping the room left for the traffic lights, which full screen hides.
- The launch screen's mark lines up with the tiles under it.
- File, Edit and View: a press outside an open menu closes it and its label no longer stays lit; one press on another label opens that menu, and with a menu open, moving the pointer along the labels switches between them.
- Every shipped language now has the launch screen's and the templates' newer lines, instead of English in their place.

All features from 0.1.10 remain included. Mobile packages are not part of this release.
