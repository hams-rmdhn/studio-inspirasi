# Studio Inspirasi 0.1.10

Desktop release of the Studio Inspirasi fork for macOS Monterey 12 (Intel) and the platforms Clovercut already ships.

## Launch screen

- Toggle between the poster grid and a compact list view of the recent projects; the choice is remembered in `prefs.json`.
- Page through the projects eighteen at a time — after search and sort — with a page bar showing the shown range and numbered pages.
- List rows gain a reveal-in-folder button on hover.
- Saved templates appear in the editor's Templates tab as a gallery with poster, size and slot count; instantiating fills placeholder slots through a sheet and deletion is a hover action.

## Fixes

- Hovering the folder and remove buttons on a project card or row no longer makes the card flicker: the buttons now keep themselves visible while the pointer is on them, instead of being shown and hidden by the card's hover in a loop.

All features from 0.1.9 remain included. Mobile packages are not part of this release.
