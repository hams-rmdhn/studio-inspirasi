# Studio Inspirasi 0.1.10

Desktop release of the Studio Inspirasi fork for macOS Monterey 12 (Intel) and the platforms Clovercut already ships.

## Launch screen

- Organise projects into categories kept in a fork-owned `project-categories.json`: a sidebar lists every category with its count, cards and rows carry a coloured badge, and each project assigns or creates a category from a tag button.
- Toggle between poster grid and a compact list view; the choice is remembered.
- Page through the projects eighteen at a time — after search, sort and category filters — with a page bar showing the range and numbered pages.
- Saved templates appear in the editor's Templates tab as a gallery with poster, size and slot count; instantiating fills placeholder slots through a sheet and deletion is a hover action.

## macOS window chrome

- In macOS fullscreen the File / Edit / View menus move to the system menu bar, matching a Mac app's own behaviour when the menu bar auto-hides and reveals.
- Fullscreen is detected from the window's own `NSWindowStyleMaskFullScreen` flag, so the traffic lights never overlap the Studio Inspirasi logo in a windowed frame.
- Pointer cursor over the strip's Layout, Shortcuts, Settings and Export buttons; cursor rectangles from the invisible title bar no longer override it.

All features from 0.1.9 remain included. Mobile packages are not part of this release.
